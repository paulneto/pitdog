# Lucky Dog Racing League: rules PitDog enforces (2026)
Source: 2026 Lucky Dog Racing League Competition Rules v1.x, https://www.racelucky.com/wp-content/uploads/2025/10/Lucky-Dog-Rules-v1.1.pdf. **Always check the event supplementals.**

| Rule | Rulebook | In PitDog |
|---|---|---|
| Race runs to the **scheduled clock** (e.g. 10:00–17:00), whatever time the green flag falls | §12 f | Race clock zero = scheduled start; checkered = scheduled end |
| **Driver stints max 2 h** ("not 2 hours 3 minutes!") | §13 b | `maxStint 120`: stint cap and alerts at 1:50 and over 2:00 |
| **60-min break** between a driver's stints | §13 b | `rest 60`: rotation skips resting drivers; rest timers |
| **Mandatory 5-min stop within every 2 h** | §13 d | `mandEvery 120`: planner cap and countdown alert |
| **Fuelling stops min 5:00** (magnetic timer; full stop at Pit In; return the timer at Pit Out) | §13 e, §9 | Fuel stop timer, green at 5:05 |
| Driver-change and mechanical stops have **no minimum** | §13 f | Stop types: fuel / driver / fix / black flag |
| Pit stops allowed **any time except red flag / all black** (work stops) | §13 c | `pitsUnderYellow 1`; RED banner; "pit under yellow" tip |
| Fuel: 5-gal racing jugs, **one jug over the wall at a time**, no funnels, max 5 people over the wall | §9 | Pit-screen reminders; jug logging |
| **Total onboard fuel ≤ 24 gal** | §6 | Plan warning if tank > 24 |
| Each fuelling infraction adds +1 min at Pit Out | §9 | (not modelled) |
| "Super Dog" too-fast lap: black flags 2 / 5 / 10 min, then DQ | §12 | (roadmap: needs lap times) |
| Pit lane 25 mph | §13 h | (info only) |
