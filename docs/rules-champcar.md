# ChampCar Endurance Series: rules PitDog enforces
Source: [2026 Basic Club & Competition Rules (BCCR) v1.4](https://champcar.org/web/pdf/2026_BCCR/2026_BCCR_V1_4.pdf), 17 Dec 2025. **Check the event supplementals.**

| Rule | BCCR | In PitDog |
|---|---|---|
| No driver drives more than **2 hours consecutively**; **60 min** rest between stints | §7.1.1 | `maxStint 120`, `rest 60` |
| Stint clock starts at green (first driver) or on release from pit lane after a change | §7.1.2 | stint timing from pit out |
| Every stop that adds fuel is a **timed stop, 5:00 min** pit-in to pit-out; non-fuel stops aren't timed | §8.2.4 | `minStop 5`, `minApplies fuel` |
| Fuel via hose or dry break on 5-gal jugs; **one jug over the wall**; **max 5 over the wall** while fuelling; ≤25 gal stored in pit | §8.2 | pit-screen reminder |
| Fuel capacity ≤ OEM (15 gal allowed if OEM < 13) | §9.10.2 | info |
| Red flag: crew stops work until the race returns to yellow | §8.3 | RED banner |
| Pits under FCY / race clock style | not specified | assumed pits open, scheduled times |
